## 🛠️ Tools

### Swift Tools
- **`app_analyzer.swift`** - iOS application binary analysis
- **`keychain_tool.swift`** - Keychain data extraction
- **`ssl_bypass.swift`** - SSL certificate pinning bypass
- **`jailbreak_bypass.swift`** - Jailbreak detection evasion

### Objective-C Tools
- **`runtime_hooks.m`** - Objective-C runtime manipulation
- **`method_swizzler.m`** - Method swizzling utilities
- **`class_dumper.m`** - Class hierarchy extraction

### Frida Scripts
- **`universal_ssl_bypass.js`** - Universal SSL pinning bypass
- **`jailbreak_hide.js`** - Hide jailbreak from apps
- **`keychain_access.js`** - Keychain item access
- **`crypto_hooks.js`** - Cryptographic function hooks

### Python Tools
- **`ipa_analyzer.py`** - IPA file analysis
- **`plist_parser.py`** - Property list parser
- **`binary_scanner.py`** - Mach-O binary scanner

## 📦 Installation

### Requirements
- macOS with Xcode
- Jailbroken iOS device (for some features)
- Frida installed
- Python 3.8+

### Quick Start
```bash
# Clone the repository
git clone https://github.com/bad-antics/nullsec-ios.git
cd nullsec-ios

# Install Python dependencies
pip install -r requirements.txt

# Install Frida tools
pip install frida-tools

# Run the analyzer
python src/python/ipa_analyzer.py --help
```
